# moood

[moood](https://moood.me) — живые анимированные миры и игры на них. **Мир** — набор сцен: места со своим настроением,
нарисованные кодом, со светом и движением; **игра** — история на мире, которую автор пишет своим кодом (игра
*bespoke*): главы, выборы, озвученные реплики, мини-игры.

Здесь — открытая часть moood: движки сцен, рантайм игры, язык мини-игр, `check` для текстов и переводов, локальный
плеер — и доки для тех, кто делает миры и игры. Пишите свои; будем рады увидеть их на moood.

## Как делать миры и игры

Миры и игры живут в вашем git-репозитории — сколько угодно и в каких угодно папках: папка с `world.json` — мир, с
`game.json` — игра, с `article.json` — статья (для сайта moood: локальный плеер показывает миры и игры). Работайте
как удобно:

- **У себя на компьютере** — запустите локальный плеер над своим репозиторием и играйте то, что делаете, сразу по
  сохранении ([player/README.md](player/README.md)).
- **В студии** — `studio.moood.me` (строится): ваш профиль, ваши репозитории, рендеры, голоса, музыка и движения,
  сделанные для вас. Доступ — спросите [pavel-zhur](https://github.com/pavel-zhur) — completely.real@gmail.com.
- **С ИИ-агентом** — Claude Code, ChatGPT, Gemini или любым другим, на своей машине или в облачной сессии: дайте
  ему [docs/](docs/README.md) — они написаны для агентов не меньше, чем для людей.

Чтобы игра появилась на moood.me, попросите в студии; перед показом её смотрят.

## Что где

- `engines/1/` — движок 1 (картины на Canvas 2D, рисует three.js на WebGL2) и сцена, на которой страницы показывают сцену (`stage.js`: любой
  движок за одним API; речь, музыка, подписи, виджеты, громкость); его страницы для рендера (`render.html`,
  `stand.html`, `motion.html`); данные людей, которые читают оба движка.
- `engines/3/` — движок 3 (WebGPU): сцена с `"engine": 3` — каждая новая.
- `scene/` — страница сцены; `host.js` — сторона страниц в договоре с хостом.
- `play/` — страница партии bespoke, её рантайм (`runtime.js`: что получает код игры) и язык мини-игр
  (`minigame/`).
- `i18n/` — языки (`languages.json`), переводчик, через который идёт каждый текст (`i18n.js`), слова страниц.
- `packages/check/` — `@moood/check`: проверка репозитория миров, игр и статей.
- `player/` — локальный плеер: миры и игры папки, показанные и сыгранные страницами (`Dockerfile` — его образ).
- `test/` — тесты (`node --test test/*.test.js`, когда `packages/check` собран: там `npm ci && npm run build`) и их
  фикстура; `test/gpu/` — проверка GPU-программ движка 3 в node (там `npm ci && node check.mjs`);
  `.github/workflows/ci.yml` — check, тесты и проверка GPU на каждый push и pull request; из `main` — образ плеера, `ghcr.io/moood-me/moood-player`; из тега `check-v<версия>` —
  `@moood/check` в npm (доверенная публикация npm: пакет доверяет `ci.yml` этого репозитория; без токена).
- `docs/host.md` — что страницы просят у того, кто их показывает; `docs/engine3/` — документы самого движка 3
  (устройство, стыки, план: тому, кто его меняет); `docs/history/` — что сделано и как.

Студии, публичного сайта и того, что делает голоса, музыку, картинки и движения (мастерской), здесь нет; страницы
просят это у хоста, а хост, который сам их не делает, — локальный плеер — берёт готовое у мастерской студии по ключу
(`docs/host.md`: The workshop).
