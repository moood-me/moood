# 2026-10-27 — локальный плеер

Ветка `player`. Плеер из договорённостей (договорённости в закрытом rpg, «Открытый репо»): миры и
игры из папки на диске — те же страницы сцены и партии, хост для них по `docs/host.md`. Как запускать —
`player/README.md`.

## Что и как

- `player/` — Node 22 без зависимостей. `server.js`: `/` — своя страница (`home.js`), `engines/`, `scene/`, `play/`,
  `i18n/` — как лежат, `/api/` — запросы контракта. Папка читается заново на каждый запрос; ничего не кешируется, кроме
  выданных по sha файлов мира.
- Живое обновление — в контракте: `GET changes?world=` / `?game=` — поток событий (`text/event-stream`), сообщение на
  каждый сохранённый файл мира (игры или её мира); страница сцены и партии открывают его сразу (`host.js follow`) и на
  сообщение перезагружаются, партия — со своего сохранения. Хост без этого отвечает 204 (EventSource не
  переподключается). Плеер: `fs.watch(root, {recursive: true})`, без скрытых файлов и папки партий, пачка сохранений — одно сообщение
  (200 мс); своя страница плеера следит за всей папкой.
- `folder.js` — порт сборки сцены из rpg (`moood/libs/worlds`: `from_files`, `strings`, `modules`): файлы папки сцены →
  спека (файл, который ничто не называет, — ошибка; файлы и папки на точку — не сцены, это записано в
  `docs/host.md`); перевод — `lang/<lang>.json`; модули — по git blob sha (`sha1("blob <len>\0" + байты)`, совпадает
  с `git ls-tree`), выданное помнится в памяти и отдаётся по `files/<sha>` навсегда. Заголовки мира, сцен, игры —
  переводятся на сервере; нет перевода — отказ `untranslated` с файлом и текстом, не английский.
- Имена мира и игры — путь в папке (`.` — корень). Поиск миров и игр — тот же, что у `check`: `units()` и `reference()`
  вынесены из `packages/check/scopes.js` в `packages/check/repository.js`, плеер берёт их оттуда.
- Партии (`plays.js`) — вне папки автора: `MOOOD_DATA` (по умолчанию `~/.moood/player`), файл на партию; одна партия на
  игру папки; restart — старая удаляется, новая с `{}`. `game.mine` — true, `version` — null; `code` — `code/<id партии>/`
  (код — живой из `bespoke/`, коммита у папки нет).
- Отказы — в контракте с кодом: `{code, values, detail}` (`not-found`, `language`, `untranslated`, `content`,
  `elsewhere`, `no-voices`, `no-music`, `request`, `failed`); страница говорит текст кода своими словами через `tr`
  (`scene/host.js refused`, переводы `scene/lang`), `detail` — только в консоль. Своя страница плеера — так же
  (`home.js`); список проблем из `check` на ней — по-английски, как `check` их говорит (для разработчика).
- Чего нет: голоса и музыка (мастерская) — `speak`, `music` отвечают 501 `no-voices` / `no-music`. Получив
  `no-voices`, `speech.js` больше не просит голосов на этой странице и говорит один раз: «нет голоса: Голоса здесь не
  делаются.»; реплики идут без голоса. `speak` у `speech.js` теперь функция страницы (`host.js voice`), а не адрес.
  Музыка молчит (`__mooodErrors`). Мир игры из другого репо (`owner/repo@ref:path`) — 501 `elsewhere`.
- Своя страница — тексты через `tr` литералами, переводы `player/lang/ru.json`, `check player` — «all right».
- `Dockerfile` в корне: `node:22-alpine`, `engines`, `scene`, `play`, `i18n`, `player`, `packages/check/repository.js`;
  папка — `/work`, партии — `/data`, порт 8080, пользователь `node`.

## Заодно

- `check`: поле статьи `about` — список ссылок той же формы, что у игры (путь от папки статьи или
  `owner/repo@ref:path`); путь — мир, игра или сцена мира.
- Комментарии, указывавшие на файлы закрытого репо (`docs/engine3`, `docs/miniux`, `dev/...`), — на доки этого репо
  (`docs/games/miniux/language.md`, `docs/games/games.md`) или без указателя.

## Как проверено

Тестовая папка (не в репо): мир и игра «Хризалиды» (`env/dev`, рядом, `world` игры — относительный путь, добавлены
`languages`) и крошечный мир движка 1 с модулем, переводом и игрой на нём. `check` по ней — all right. Все 19 сцен
мира собираются на en и ru, sha модулей совпадают с git; спека `threads` — та же, что отдаёт студия. Chromium из
Playwright, локально и в docker-контейнере: страница плеера (en, ru); сцена движка 1 и партия — без ошибок в консоли,
кроме ожидаемого 501 на голос; клик по фонарю → сохранение → после перезагрузки сохранено; ↺ — новая партия; правка
`scene.json` видна при следующем открытии (а без перевода на ru — честный отказ); все запросы — только из контракта.
Движок 3 в headless не встаёт (WebGPU) — проверены только запросы: сцена, мир, весь код игры; отрисовку — на машине с GPU.
Потом: две реплики без голоса — один запрос `speak` и одна надпись на загрузку; правка `game.js` — партия
перезагрузилась с сохранением (фонарь горит); непереведённый заголовок — отказ по-русски, сохранён перевод — сцена
открылась сама; своя страница плеера перезагружается; мир из другого репо — по-русски.
