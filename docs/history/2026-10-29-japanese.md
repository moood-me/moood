# 2026-10-29 — Japanese (`ja`)

Why: Павел: ещё язык — японский.

- `i18n/languages.json`: `ja` — `{ "name": "日本語", "locale": "ja_JP" }`, after `ru`. Japanese has one plural form:
  `Intl.PluralRules('ja')` says `other` only, so a `tr.n` entry's translation in `ja` is `{"other": "…"}` (`check
  --write` lays it out so).
- moood's own pages translated beside the Russian: `engines/1/lang/ja.json`, `engines/3/lang/ja.json`,
  `play/lang/ja.json`, `player/lang/ja.json`, `scene/lang/ja.json`, `packages/check/problems/lang/ja.json`. From the
  English source, the Russian read beside it; polite but light (です/ます in sentences, short labels); a play is
  「プレイ」, a line 「セリフ」, a world 「世界」, a quota 「利用枠」; spans of time (`scene/span.js`) — `{n}日`, `{n}時間`, `{n}分`,
  `{n}秒` (`{again}後に`).
- The tests that name moood's languages (`test/check.test.js`, `test/player.test.js`) — `en, ru, ja`.
- How it was checked: `npm ci && npm run build` in `packages/check`, then `node packages/check/cli.js <folder>` for each
  folder of moood's pages (`engines/1`, `engines/3`, `play`, `player`, `scene`, `packages/check/problems`) — `--write`
  laid the files out, then each says «all right».
