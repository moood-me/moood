# Spanish, a third language (2026-10-29)

**Why.** Павел: «ещё язык — испанский». moood speaks English (the source), Russian and now Spanish (`es`), beside
the Ukrainian and German done at the same time in their own branches.

**What.** `i18n/languages.json`: `"es": { "name": "Español", "locale": "es_ES" }`, described as `ru` is. moood's own
pages translated: `engines/1/lang/es.json`, `engines/3/lang/es.json`, `play/lang/es.json`, `player/lang/es.json`,
`scene/lang/es.json`, `packages/check/problems/lang/es.json` — from the English, with the Russian as a second view.
Neutral international Spanish, «tú» for the person; placeholders and `{…}` kept; plurals in Spanish's forms
(`one`, `many` — a million and up: «{n} de días» —, `other`). The tests that name moood's languages
(`test/check.test.js`, `test/player.test.js`) now say `en, ru, es`.

**How.** `npm ci && npm run build` in `packages/check`; `node packages/check/cli.js <folder> --write` for each
folder CI checks (it lays out `lang/es.json` with empty translations), the translations filled in, then
`node packages/check/cli.js <folder>` — "all right" for each of them.
