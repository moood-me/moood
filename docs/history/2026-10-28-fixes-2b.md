# 2026-10-28 — музыка только по POST, отказы словами страницы, общее с хостами (fixes-2b)

Ветка `studio-f2b`. Что нужно было студии после её fixes-2a (её docs/history/2026-10-28-fixes-2b.md).

## Что и как

- **Музыка** (`engines/1/music.js`): запись начинает только `POST music`, `GET` только слушает. Страница даёт музыке
  `MooodMusic.init({track, listen, silent})` — `scene/host.js` `music` (`track` — POST → ключ, `listen` — GET → поток;
  отказ — Error словами страницы с `code`, как у голоса), `silent(why)` — сказать в углу. Поток, который кончился
  (событие `ended` или закрыт) или оборвался (TypeError соединения) до того, как запись целая, — значит её делание
  упало или потерялось (инстанс хоста ушёл): страница снова POSTит (через AGAIN с, не больше TRIES раз подряд, пока
  ничего нового не слышно). Отказы: `no-music` — сказано раз, музыку больше не просим; `quota` — сказано, эту музыку
  больше не просим; `request` и прочее — сказано.
- **Пределы Lyria** — в одном месте: `MooodMusic.LIMITS` (bpm 60–200 целое — страница округляет, density и brightness
  0–1, шкала из Lyria, не больше 20 звучащих описаний по 500 символов). `check` говорит их о `music` сцены кодом
  (`music-prompts`, `music-text`, `music-range`, `music-scale` — слова в `problems.js`, перевод рядом); `npm run build`
  кладёт `engines/1/music.js` в пакет. Хост, который их не берёт, отказывает `request` (docs/host.md).
- **docs/host.md**: POST начинает, GET слушает, что делает страница, когда поток кончился; пределы; новые отказы
  `busy {again}` (речь) и `streams {most}` — у страниц на них есть слова (`scene/host.js`, перевод).
- **Без inline-скриптов**: часы плея — `play/clock.js`; политика хоста может быть `script-src 'self' 'unsafe-eval'`
  без хэшей (docs/host.md).
- **Общее с хостами**: `scene/span.js` — `spans(lang)` → промежуток секунд словами (страницы moood и студии; слова —
  `scene/lang`); `player/types.js` — `typeOf` (плеер, студия); `packages/check/repository.js` `blobId` — id содержимого
  файла (sha блоба git). `problems.js` без Node (`strings` ушёл): его говорит и страница в браузере, загрузив перевод
  рядом как любую часть страниц (`i18n/words.js`); плеер читает его сам.
- **docs/worlds/README.md**: `render_scene` берёт `set` (значения по ходу, как ставит игра) и `views` (камеры каждого
  момента листа или пачки) — студия их теперь передаёт.
