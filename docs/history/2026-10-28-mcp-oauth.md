# 2026-10-28 — как агент подключается к MCP студии: OAuth; мир не публикуется сам

Ветка `studio-6b` (для этапа 6b студии: её MCP принимает OAuth — claude.ai, Claude Code подключаются без токена,
человек разрешает на странице студии; токены из профиля истекают; в каталоге нет записи «мир»).

## Что и как

- `docs/README.md` — абзац о подключении: OAuth (claude.ai — «Add custom connector», Claude Code — `claude mcp add` и
  `/mcp` → Authenticate) или токен из профиля («Агенты» → «Токены»).
- `worlds/README.md` — MCP подключается по OAuth или токеном; ссылка на файл берётся токеном из профиля (по OAuth —
  просить содержимым); что видно на сайте — опубликованное: игра (с коммитом своего мира), набросок или «скоро» на
  коммите мира; мир сам не публикуется.
