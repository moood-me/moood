# 2026-10-28 — страницы moood на публичном сайте: свой адрес страницы, путь назад (studio-5a)

отдельный процесс студии, страница партии на нём — moood'овская, по договорённостям
(в закрытом rpg), «Открытый репо»: «страницы сцены и партии — те же, что берут из открытого репо публичный сайт и студия»).

## Что и как

- **Свой адрес страницы** (`scene/host.js` `asked`): что страница показывает (`world`, `scene`, `game`, `lang`) — из
  query её адреса, а у хоста, который отдаёт её по своему адресу (публичный сайт: `/<язык>/play/<слаг>`), — из
  `<meta name="moood-page" content="game=…&lang=…">`, которую он вставил (так же, как `moood-host`). `scene/scene.js`,
  `play/play.js` читают из него.
- **Путь назад** (`play/play.js`, `play.css`): `GET play` может ответить `back` — адрес страницы игры у хоста
  (относительно `H`); тогда первым в баре — «← название игры». Нет — нет (студия и локальный плеер пока не дают).
- **docs/host.md** — оба пункта.

## Как проверено

- `node --test test/*.test.js` (10); `check` над `scene/`, `play/` — всё переведено.
- В студии (её 5a, закрыта): её `test/site.test.js` (страница партии на сайте — moood'овская, с `moood-page` и `<base>`), docker
  compose и Playwright en/ru — партия на публичном сайте с «← Фонарь», без ошибок в консоли.
