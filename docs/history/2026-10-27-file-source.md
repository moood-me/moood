# 2026-10-27 — репо через источник файлов

Ветка `studio-2a`. Для студии (этап 2a, `moood-me/studio`): сборка сцены и поиск миров/игр/статей — одни на всех
хостов, но студия читает не папку, а git-дерево коммита на GitHub. Поэтому чтение репо вынесено в маленький интерфейс.

## Что и как

- `packages/check/repository.js`: источник файлов репо — `list(dir)` → `[{name, dir}]` или null, `read(path)` → текст
  или null (оба async: у студии это запросы к GitHub); `folder(root)` — папка на диске как источник. `units(source)` —
  тот же поиск, что был, теперь через источник (async, детей обходит параллельно, порядок — прежний). `reference()` для
  чужого репо отдаёт части: `{foreign: {repo, ref, path}}` (было `{foreign: true}`), чтобы хост мог его открыть.
- `check`: `scopes()`, `check()`, `lines()` — async (ждут `units`); `cli.js` — `await`. Вывод `check` на мирах
  «Хризалид», тестовом и папке плеера — байт в байт прежний.
- `player/folder.js`: вся сборка — через источник: `contents`, `world`, `game`, `worldIn`, `sceneIn`, переводы
  заголовков — async от `source` вместо `root`. Файлы модулей — `source.id(path)` (id содержимого, git blob sha): у
  плеера — хеш файла, выданное помнится (`server.js`), у студии — sha из дерева. `sceneIn` больше не пишет `files`:
  адрес файлов — дело хоста. `worldAt(g)` — где мир игры (путь в её репо или чужое `repo@ref:path`); `worldOf` — как
  был: чужое — отказ `elsewhere` (плеер), студия чужое открывает сама. `within()` переехал в `server.js` (нужен только
  ему).
- `docs/host.md`: имена студии (`owner/repo@ref:path`) и одна сборка на всех хостов.

## Как проверено

Плеер до и после на одной папке (мир и игра «Хризалид», тестовый мир движка 1 с модулем, переводом и игрой): ответы
`world`, `scene` (все сцены, en и ru), `files/<sha>`, `play`, `code` — те же (кроме слова в `detail` отказа), страница
плеера та же, `changes` сообщает о сохранённом файле так же. Студия собирает той же сборкой сцены из git-дерева
настоящего GitHub (`moood-me/pavel--chrysalids`, `env/dev`: 19 сцен, id модулей = git blob sha) — см. историю
этапа 2a в `moood-me/studio`.
