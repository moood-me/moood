## Хост

Страницы ходят только в контракт `docs/host.md`: адрес — `<meta name="moood-host">`; запросы — `world`, `scene`,
`play`, `restart`, `speak`, `music` с id в query (id мира — путь в репо, со `/`), файлы мира — по адресу, что дал хост
(`files` + sha; `kit.js` обоих движков, вместо `/api/worlds/<id>/blobs` и черновиков `/modules`), код игры — `code`.
Новые страницы: `scene/` (`index.html`, `scene.js`, `host.js`), `play/` (`index.html`, `play.js` — панель как у
публичного сайта, кнопки строит JS с `tr`). `music.js` — только запись по ключу (настройки автора, живая сессия и
панель — студии); `select.js` — без карточки (moood/free); метрики — `globalThis.MooodSeen`, если хост его поставил.

## Формат и check

Репо — папка: `world.json` / `game.json` / `article.json` на любой глубине, внутрь не ищем, два в одной папке —
ошибка. `"languages"` у каждого; переводы проверяются только в них; игра — только в языках своего мира (и миров своих
`scenes`). Ссылки игры: путь от её папки или `owner/repo@ref:path` (только форма). Статья: `article.json`
(`title`, `date`), `story.md`, переводы `article.<lang>.json`, `story.<lang>.md`. В пакете вместо `bespoke/` — `play/`;
`site.json` из `FIELDS` убран (публичный сайт). Лицензия — MIT.

## Как проверено

`moood-check` на тестовом репо (мир, игра, мир-набросок, статья; и с ошибками) и на `engines/1`, `engines/3`, `play`,
`scene` (`--write`, русские переводы). Заглушка хоста (не в репо) + Chromium из Playwright: сцена движка 1, партия на
нём (реплика с голосом, сохранение, выбор, пауза, громкость), `render.html` — без ошибок, запросы только по контракту.
Движок 3 в headless здесь не встаёт (адаптер есть только в воркере, устройство сразу теряется) — страница честно
говорит «не удалось показать»; его отрисовку надо проверить на машине с GPU.
