# 2026-10-29 — Korean (`ko`)

Why: Павел: и корейский — Korean as a further language.

- `i18n/languages.json`: `ko` — `{ "name": "한국어", "locale": "ko_KR" }`. Korean has one plural form:
  `Intl.PluralRules('ko')` says `other` only, so a `tr.n` entry's translation in `ko` is `{"other": "…"}`.
- The tests that name moood's languages (`test/check.test.js`, `test/player.test.js`) name `ko` too (commit 654242d).
  They were not run here: they need Linux paths.
- moood's own pages translated: `engines/1/lang/ko.json`, `engines/3/lang/ko.json`, `play/lang/ko.json`,
  `player/lang/ko.json`, `scene/lang/ko.json`, `packages/check/problems/lang/ko.json`. From the English source, the
  Russian and Japanese read beside it. Register: what players see (play, player, scene, the engines) in polite 해요체
  («플레이를 열지 못했어요»), check's problems — read by authors — in 합니다체 («번역되지 않았습니다»); buttons and labels
  short nouns («계속», «일시 정지»). Terms: world 세계, game 게임, scene 장면, line 대사, voice 음성, music 음악, play 플레이,
  quota 할당량, repository 저장소; spans of time (`scene/span.js`) — `{n}일`, `{n}시간`, `{n}분`, `{n}초`
  (`{again} 후에`).
- How it was checked: `node packages/check/cli.js <folder>` for each folder of moood's pages (`engines/1` 115 texts,
  `engines/3` 4, `play` 21, `player` 15, `scene` 25, `packages/check/problems` 72) — each says «all right».
